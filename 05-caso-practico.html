3.4 Caso práctico

Objetivo del caso

Integrar las técnicas del tema en un flujo reproducible sobre un dataset multivariado (p. ej. iris, penguins o un CSV de negocio).

Pipeline recomendado

  1. Carga y limpieza: tipos, NA, outliers evidentes.
  2. EDA univariada y bivariada: histogramas, boxplots, correlaciones, pairplot.
  3. Estandarización de variables numéricas para PCA/MDS.
  4. PCA: varianza explicada, scores PC1–PC2 coloreados por categoría, loadings.
  5. MDS: mapa 2D a partir de distancias euclidianas; comparar con PCA.
  6. (Opcional) t-SNE: explorar clusters locales; documentar perplexity y semilla.
  7. Serie o patrón periódico (si hay variable temporal): línea + espectro básico.
  8. Mini-dashboard: 3–5 gráficos clave con un mensaje conjunto.
  9. Conclusiones: qué estructura se vio, limitaciones, siguientes preguntas.

Preguntas guía para el informe

  • ¿Cuánta varianza explican los dos primeros componentes?
  • ¿Los grupos etiquetados se separan en el plano PCA/MDS?
  • ¿Qué variables empujan PC1 y PC2?
  • ¿t-SNE cambia la lectura de los grupos? ¿Por qué podría diferir?
  • Si hay estacionalidad, ¿qué periodo domina?
  • ¿Qué decisión de negocio o investigación sugiere el tablero?

Entregables sugeridos

  • Notebook ejecutado (HTML o .ipynb) con código y figuras.
  • 1 página de conclusiones en lenguaje claro (sin jerga innecesaria).
  • Captura o sección de “tablero” con KPIs + 2–3 gráficos.
El notebook practica_visualizacion.ipynb implementa el esqueleto de este caso con datos de ejemplo listos para adaptar.
